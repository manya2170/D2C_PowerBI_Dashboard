# D2C_PowerBI_Dashboard
D2C business analysis dashboard built with Power BI, Power Query, and DAX.

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze
D2C business performance across sales, costs, vendors,
and marketing.

## 🎯 Objectives

- Analyze sales performance
- Track important business KPIs
- Analyze vendor costs
- Evaluate volume discounts
- Monitor marketing performance
- Create interactive business dashboards

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modelling
- Data Visualization

## 📑 Dashboard Pages

### 1. Executive Dashboard

Provides an overview of sales and business performance.

### 2. Cost & Vendor Analysis

Analyzes product costs, volume discounts and vendor
payables.

### 3. Marketing Performance

Analyzes marketing spend, budget, ROAS, CTR, CPC,
clicks and impressions.

## ⚡ Key Features

- Interactive slicers
- Cross-filtering
- KPI cards
- DAX measures
- What-if parameter
- Interactive visualizations
